# Faseo vigente — Méntor web compartido

Este plan sustituye como ruta principal el faseo de escritorio a petición del usuario el 19/10/2026. Conserva los siete módulos y las fórmulas auditadas. Cada entrega se revisa antes de comenzar la siguiente.

| Fase | Entrega | Criterio de cierre |
|---|---|---|
| W1 — Base web compartida | Acceso privado, proyectos, ficha general, escenarios vacíos, invitaciones, roles e historial | Compilación, aislamiento entre proyectos, prueba entre cuentas, persistencia y control de edición concurrente; vista previa revisable |
| W2 — Acceso por internet | Alojamiento elegido, dominio HTTPS, persistencia central, operación de cuentas, respaldo y restauración inicial | Dos personas en equipos diferentes trabajan sobre el mismo proyecto, sin publicar datos de prueba ni secretos |
| W3 — Motor compatible | Fórmulas físicas/económicas originales separadas de UI y servidor | Paridad con referencias HTML y caso del PDF, con redondeos documentados |
| W4 — Terreno y edificio | Áreas, niveles, sótanos, dúplex por grupos, azoteas y documentos con fuentes urbanísticas | Sin doble conteo; fuentes compartidas y estados pendientes explícitos |
| W5 — Economía configurable | Supuestos por escenario, tarifas excluyentes, partidas manuales y áreas condicionadas | Aislamiento, costos no duplicados y resultados reproducibles |
| W6 — Volumetría | Three.js, niveles, vistas y PNG | Coherencia con motor; el fallo del visor no interrumpe los cálculos |
| W7 — Comparador y biblioteca | Cuatro escenarios vigentes del mismo terreno, plantillas versionadas e independientes | Sin propagación no autorizada ni resultados obsoletos |
| W8 — Informes | Ejecutivo y completo, A4 mixto, archivos emitidos inmutables y permisos | Igualdad de cifras, calidad visual y conservación de versiones |
| W9 — Validación del producto | Recorridos completos, concurrencia, seguridad, restauración y operación | Aceptación de usuarios y plan de mantenimiento documentado |

La referencia PEDelta orienta navegación, filtros, paneles y jerarquía visual. No se copian sus datos, identidad ni funciones ajenas al evaluador inmobiliario. La primera vista previa utiliza el servidor de este equipo: todavía no equivale a acceso público por internet.
